Questions fréquentes

Comment rejoindre l'album d'un bébé ?
Un parent t'envoie une invitation avec un code (par exemple LUNE-7KQ4). Ouvre Soleïa, touche « J'ai reçu une invitation » et tape le code.

Je n'ai pas reçu le code de connexion.
Regarde dans les spams, puis touche « Renvoyer un code » après une minute.

Qui voit les photos ?
Uniquement les personnes invitées par les parents. Rien n'est public, jamais.

Comment supprimer mon compte ?
Dans l'app : Mon compte, puis « Supprimer mon compte ». Tout est effacé immédiatement.
